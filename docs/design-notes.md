# 设计依据

## 学习机制

- 主动提取（测试效应）：Roediger & Karpicke, 2006。
- 间隔学习：Cepeda et al., 2008。
- 自我解释：Chi et al., 1994。
- 变化例子与迁移：Butler et al., 2017。

这些研究支持同一个方向：学习后的主动回忆与自我解释，比重复阅读更能形成可迁移的理解。系统把它们落成「先提问、再作答、后反馈」的固定顺序。

## 笔记组织

- 原文与个人理解分离：资料页只保留客观信息与覆盖状态，理解写进「我的笔记」。
- 单一事实来源：任务与证据只在原页维护，首页与其他页面只引用。
- 轻量模板：零必填，允许从一句话开始，降低启动成本。

## 平台选择

- 思源内容块有独立 ID，适合块级检索、引用和局部更新。
- 工作区 Agent 用 `AGENTS.md` + `SKILL.md` 固化流程，避免规则散落在聊天记录里。
- 同步可自建（S3 / WebDAV），数据与备份可控。

## 明确不做

- 不做每日打卡、精力模式、连续天数。
- 不做总分、百分比、排名。
- 不做后台监控与自动迁移。
- 不用 AI 摘要替代原文。
