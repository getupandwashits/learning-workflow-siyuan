# 系统结构

一个工作区、一个主笔记本「学习与成长」，所有内容按角色分页，不按信息来源或时间堆叠。

```text
学习与成长/
├── 首页
├── 使用说明与模板/
│   └── 模板入口（项目 / 学习 / 原则 / 阶段复盘）
├── 项目/
│   └── <项目名>            # 一个真实项目一则主笔记
├── 我的笔记/               # 自己的理解、原则、心得
├── 参考资料/               # 原文、课程、报告、仓库入口
├── 成长档案/
│   ├── 方向与约束
│   ├── 学习索引
│   └── 能力与证据
└── 随手记录与阶段复盘/
```

## 各页面职责

| 页面 | 放什么 | 不放什么 |
|---|---|---|
| 首页 | 当前项目、近期下一步、待回忆入口、常用入口 | 状态副本、第二套任务清单 |
| 使用说明与模板 | 使用约定、四个模板入口 | 具体项目的私货 |
| 项目 | 目标与阶段判据、进展、阻碍、下一步、起点、复盘 | 长篇资料摘抄 |
| 我的笔记 | 自己的解释、原则、类比、心得 | 原文、AI 草稿 |
| 参考资料 | 出处、作者 / 年份、版本、标签、覆盖状态 | 概述性导读、个人理解 |
| 成长档案 | 可观察能力、证据引用、未知、下一步 | 总分、百分比、排名 |
| 随手记录与阶段复盘 | 暂时无归属的进展、心得、阶段复盘 | 长期不整理的大杂烩 |

## 引用规则

- 一个动作只建一次：任务原块留在项目页或学习页，首页只引用原块。
- 关键关系用一句说明 + 引用，不复制整段内容。
- 引用应指向原记录；找不到原记录时保留出处文字，不伪造链接。

## 标签约定

- `用途/核心`：直接服务当前问题。
- `用途/背景`：有参考价值，不是当前核心。
- `用途/暂不适用`：已判断当前不用。
- 核验状态写在资料页内，不另设标签；未标记表示尚未评估，不等于低质量。

## Agent 文件位置

| 文件 | 路径 |
|---|---|
| 工作区约定 | `<工作区>/data/ai/AGENTS.md` |
| 技能 | `<工作区>/data/storage/ai/agent/skills/<name>/SKILL.md` |
| 模板片段 | `<工作区>/data/templates/*.md` |

思源版本建议 3.8.8 及以上（支持工作区 Agent 指令与技能）。
