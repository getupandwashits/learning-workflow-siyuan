# 四个工作流

工作流由自然语言触发，不要求用户背诵命令。完整规则见 [`ai/AGENTS.md`](../ai/AGENTS.md)。

## 资料与关联

**触发**：「审阅这些资料」「这个仓库值得看吗」「把这篇论文收进资料库」。

1. 确认材料类型（文件 / 网址 / 选中内容）与要解决的问题。
2. 核对出处、作者 / 机构、年份 / 版本；能取正文就取正文，取不到就明确说明。
3. 区分「只有链接」「只有摘要」「正文可读」「全文检索已验证」「语义召回已验证」。
4. 资料页只留客观信息与覆盖状态；个人理解写进「我的笔记」。
5. 质量建议必须有依据；收藏不自动变成任务。

## 项目建立与规划

**触发**：「帮我建立项目」「接下来推进什么」「这个方案怎么选」。

1. 提取目标与当前阶段结果；读取已有方向、能力证据与资料。
2. 只澄清会改变范围或下一步的信息，未知明确保留。
3. 每个项目一则主笔记：目标、阶段判据、进展、阻碍、下一步、起点、复盘。
4. 能力用可观察动作描述；建议与已接受任务分开。
5. 选型时明确约束，检索少量候选，回到官方文档 / 源码 / Release Notes 核对。

## 学习与主动回忆

**触发**：「刚学完，开始回忆」「考考我」「这部分我讲讲」。

1. 先确定核心问题，读取足够来源以核对答案。
2. 提出一个问题，告诉用户先不看原文；**本条回复到此结束，等待作答**。
3. 不在提问时附答案、摘要或泄露结论的提示。
4. 收到真实尝试后再反馈：哪些成立、哪里遗漏或误解、来源能确认到什么程度。
5. 在原学习笔记记录问题、原话、提示条件、反馈与修正；状态从「待回忆」按实际更新。

> 这是同步流程：Agent 不能在你作答前预生成反馈，也不应该预生成。原因见「已知限制」。

## 复盘与成长评估

**触发**：「帮我复盘」「这阶段有什么变化」「更新能力档案」。

1. 读取项目起点、进展、个人心得、回忆与旧复盘。
2. 区分用户报告、可核实结果、外部来源与 AI 假设。
3. 只比较有条件的可观察能力；没有基线不编造成长幅度。
4. 建议少量、有依据、可停止；不自动增加待办。
5. 项目完成、回忆完成、个人掌握分别判断。

## 共性规则

- 先读后写，局部更新，不覆盖用户正文。
- 不直接编辑 `.sy` 文件，使用思源提供的读取 / 搜索 / 写入能力。
- 首页只在确有新增时更新引用，不制造占位条目。
- 不设打卡、精力模式、总分或必须补齐的历史欠账。
