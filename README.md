# learning-workflow-siyuan

> 把「真实项目 + 精选输入 + 主动回忆」固化成一套思源笔记结构与 Agent 工作流。
> An agent-driven engineering growth workflow for SiYuan Note: project-first, curated inputs, active recall.

## 它解决什么

- **学完就忘**：AI 讲解后必须自己复述，AI 不替你答。
- **AI 输出失真**：参考资料只收原文与高质量沉淀，未经精校的 AI 内容不入库，减少二次加工带来的失真。
- **成长玄学**：能力用可观察动作与证据记录。

## 四条原则

1. **项目优先**：先推进真实项目，资料与学习服务于项目，用产出推进学习。
2. **筛选输入**：只选择高质量内容作为参考，不导入任何未经精校的 AI 内容。
3. **原文即数据**：原文就是最好的数据，除论文时间、发表单位等客观内容外，不对高质量内容进行任何二次加工。
4. **反馈学习**：讲就是学，做就是学，阅读资料后通过自我讲解重新建立神经突触。

## 为什么用思源

- 复用已有的 Agent 工作流（`AGENTS.md` + skills）。
- 内容块有独立 ID，可单独检索、引用、局部更新。
- 同步可自建（S3 / WebDAV），数据在自己手里。

## 结构

```text
学习与成长/
├── 首页                  # 当前项目、下一步、待回忆入口
├── 使用说明与模板        # 4 个模板与使用约定
├── 项目/                 # 每个真实项目一则主笔记
├── 我的笔记/             # 自己的理解与表达
├── 参考资料/             # 原始出处与覆盖状态
├── 成长档案/             # 方向与约束 · 学习索引 · 能力与证据
└── 随手记录与阶段复盘/
```

## 四个工作流

| 你说 | 触发 | 产出 |
|---|---|---|
| 「审阅这些资料」 | 资料与关联 | 出处 / 版本 / 覆盖状态，不写二手导读 |
| 「建立项目 / 推进什么」 | 项目规划 | 目标、阶段判据、下一步 |
| 「刚学完，开始回忆」 | 主动回忆 | 先提问，等你作答，再反馈 |
| 「帮我复盘」 | 复盘评估 | 有证据的变化、缺口、下一步 |

## 上手（5 分钟）

1. 从 Releases 下载 `learning-workflow-siyuan-starter.sy.zip` 导入思源（得到笔记本「学习与成长-上手骨架」）；或下载 Markdown zip 用「导入 Markdown .zip」。
2. 从仓库取文件：`ai/AGENTS.md` 放到工作区 `data/ai/`，`ai/skills/*` 放到 `data/storage/ai/agent/skills/`，`templates/*.md` 放到 `data/templates/`。
3. 打开「首页」，对 Agent 说：**首次校准**。
4. 建第一个真实项目，开始。

首次校准提示词：

```text
读取 AGENTS.md 的工作区约定。按标题在思源中定位：首页、项目、我的笔记、参考资料、
成长档案（方向与约束 / 学习索引 / 能力与证据）、随手记录与阶段复盘、
使用说明与模板、模板入口。确认存在后，把各自文档 ID 补到 AGENTS.md 的「位置」一节；
缺失的按结构创建。不要修改已有正文。
```

## 已知限制

- **同步对话，无法异步预生成反馈。** 回忆问题必须等你真实作答后才给反馈——这是为了不泄露答案、不替你思考。代价是不能并行，只能一轮一轮来。
- **单轮约 2 分钟。** 当前配置为 opencode-go 订阅 + `glm-5.3-flash`，实测每次交互约 2 分钟。建议一次给足背景、减少轮次。
- **DeepSeek v4.1 不兼容。** 其输出格式偏好与本工作流（思源 Markdown / 结构化回合）冲突，暂不使用；推荐 `glm-5.3-flash` 或格式稳定的模型。
- **无后台能力。** 不监控社区更新、不打卡、不自动评分。
