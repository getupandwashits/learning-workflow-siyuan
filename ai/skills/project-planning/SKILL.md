# 项目建立与规划

## 位置

- 默认笔记本：学习与成长；项目入口：项目；首页：首页。
- 个人笔记：我的笔记；方向：成长档案 / 方向与约束；能力证据：成长档案 / 能力与证据；模板：模板入口。
- 首次使用时按标题定位；可把实际 ID 记录到 `AGENTS.md` 的「位置」一节。
- 用思源工具读取、搜索、局部写入与引用；不直接编辑 `.sy`。先检查是否已有同一项目，避免重复建立。
- 按实际需要读取「模板入口」下的对应模板，不要求用户先填满模板。

## 建立项目

1. 从用户描述提取希望完成的事和当前阶段结果。读取相关方向、能力证据与已有项目记录；优先使用已有资料，再按实际缺口补找来源。
2. 只澄清会改变范围、阶段结果或下一步的缺失信息。已有授权足够时直接将可确定部分写成项目草案，未知处明确保留。
3. 每个真实项目先有一则主笔记：目标与阶段结果；当前进展、问题与下一步；相关知识资料与能力；起点记录；过程与阶段复盘。复杂后再拆子笔记。
4. 将知识与能力分成当前确实需要、推进中再补、以后探索。能力用可观察的动作表达，例如解释机制、实现某一步、选择测量和处理变化情境；不把整条学习路线变成启动门槛。
5. 起点引用已有个人解释、项目经历或回忆记录。自述标为自述；AI 推定的需求标为建议；无证据保留未知。保留带日期的起点，不在后续更新时覆盖。
6. 提出少量下一步，说明理由、资料依据、服务的能力和可停止的范围。只有用户选定或已明确要求执行的计划才进入当前任务；其余留为建议。

## 推进与指导

用户说进展时，更新实际阶段、阻碍及下一步；区分用户报告、已核实结果与待检验假设。不因为听到「跑通了」就宣布项目全部完成或个人已掌握。

需要补学核心概念时，连接或建立学习笔记，并留下待回忆问题；关键学习完成前须有用户自己的提取尝试，再核对反馈。普通进度更新与临时查参数不自动变成考试。

项目任务保留在项目主笔记或已有子笔记；独立学习动作保留在学习笔记。一个动作只建立一次，首页与其他页面引用原任务块，不复制另一套复选框或进度字段。

已有计划可以缩小、取消或搁置，并保留变更原因。允许纯学习和兴趣探索，不要求所有资料绑定项目，不建立精力模式或打卡要求。

## 首页同步

本次实际新增项目、学习任务、待回忆、资料质量标记或复盘时，读取首页，仅局部更新对应小节的原块引用，保留用户正文。项目任务原块在项目笔记，独立学习任务原块在学习笔记；首页只引用原块，不复制另一套复选框或状态。没有实际记录变化时不为刷新首页制造条目。

## 回复

给出项目链接、已确定的阶段与起点、当前最重要的下一步以及影响推进的未知。重要问题解决或阶段结束时，建议用原始进展与学习证据进行复盘；不要虚构用户尚未进行的行动或增长。

## 项目选型与知识参考

用户开始真实项目或提出选型问题时，先明确目标及真正影响选择的约束，再主动检索社区已有方案并阅读原始来源。比较少量合适候选，说明适用性、维护与稳定性、文档或源码依据、条件、取舍和未知；不以 Stars、热度或「能做到」代替成熟度与使用证据。

仓库收藏只是知识来源，不默认安排克隆、安装、运行或性能测试。纯阅读不需要先具备 GPU 或环境。用户未来明确要求的实际项目操作另按当次范围处理。性能只从来源能支持的环境与工作负载描述，没有实测不宣称本机有效。

项目页按需保留选型候选、推荐理由、依据版本与核验日期；建议与已接受决定分开。下一步可为阅读、机制解释、方案比较与回忆，不自动变成仓库运行清单。
