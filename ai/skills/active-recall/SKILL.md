# 学习与主动回忆

## 位置与对象

- 默认笔记本：学习与成长；学习笔记：我的笔记；资料：参考资料；学习索引：成长档案 / 学习索引；首页：首页。
- 首次使用时按标题搜索确认这些文档，可把实际 ID 记录到 `AGENTS.md` 的「位置」一节。
- 优先使用当前明确指定的学习笔记、原资料和已有回忆块。先读取目标，再以思源工具局部更新；不直接编辑 `.sy`。
- 按实际需要读取「模板入口」下的对应模板，不要求用户先填满模板。

## 确定学习单元

围绕一个明确问题学习过的一段内容才是关键单元，例如一节课的核心机制、论文的重要方法或项目中补学的概念。收藏链接、记进度或临时查参数无需逐条出题。陌生内容可以先提供必要教学，再进入学后的提取。

关键单元须经历一次用户自己的提取尝试与核对。未尝试时保留「待回忆」；这与资料已读、项目进度及能力掌握分别记录。

## 提问阶段：必须停下来等待

1. 读取足够来源以确定核心目标与可核对答案，核实实际覆盖范围。
2. 默认提出一道能检验机制、条件、比较或变化情境的问题，允许几句话、图示、推导或口述式回答。
3. 告诉用户先暂时不看原文和答案，用自己的话尝试。首个提问响应到此结束，等待下一条用户回答。
4. 不在同一响应附标准答案、参考解释、答案摘要或揭示关键结论的提示；不要自问自答，也不要替用户填写回忆表现。

只有用户真实回答、明确表示想不起来或主动请求提示，才进入反馈阶段。用户提供的既有真实尝试可直接用于反馈，无需机械重复提问。用户停止时保持待回忆，不强制继续会话。

## 反馈阶段

核对实际尝试：哪些成立、具体遗漏或误解在哪里、来源能确认到什么程度。先给必要纠错；不确定或资料冲突时明确标待核实，不用模型自信代替依据。

「想不起来」也算一次尝试，可以给逐步提示与教学，但不记为独立解释。获得提示后的回答与看到答案后的复述分别记录。答错不等于没有学习，答对一次不等于长期掌握或迁移。

在原笔记追加日期、问题、用户尝试原文或忠实引用、提示／看答案情况、来源反馈和必要修正。保留用户原话，不用润色后的 AI 表达替代评估证据。若未完成核对，注明状态。

可建议同类新情境或后续重访，但不一次生成大批题目和待办。复习只选重要机制、反复混淆和即将使用的内容；根据表现与用途调整，不声称固定日期能准确预测遗忘。

## 首页同步

本次实际新增项目、学习任务、待回忆、资料质量标记或复盘时，读取首页，仅局部更新对应小节的原块引用，保留用户正文。项目任务原块在项目笔记，独立学习任务原块在学习笔记；首页只引用原块，不复制另一套复选框或状态。没有实际记录变化时不为刷新首页制造条目。首轮同步只保存真实的待回忆记录，不代填用户回答或反馈。

首版通过会话顺序与笔记记录落实要求，不宣称已经实现软件拦截、定时推送或自动测量掌握程度。学习产生的证据可供成长评估引用，当前题目表现本身不替代全面能力判断。

## 知识来源与版本

开源仓库可以直接作为文档、设计和源码知识来源，不要求克隆或运行后才能学习。具体实现或版本相关内容在教学前按需核验引用版本与必要原始来源；基础原理不机械重复搜索。未取得正文或未核验时说明覆盖与不确定性。

回忆可以检验机制、推导、设计取舍和边界。代码阅读与独立实现、运行或调优分别判断，不用不存在的实践充当证据。资料更新本身不自动追加考试；确实学习新关键内容时仍须先提问、等待真实尝试，再反馈。
